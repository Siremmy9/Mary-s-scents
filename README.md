# Mary's Scent — Vanilla JS E-commerce + Business Dashboard

A frontend-only luxury fragrance store and business management demo built with **HTML5, CSS3, Vanilla JavaScript and LocalStorage**.

## Run
Open `index.html` in a browser. For best results, use VS Code + Live Server.

## Admin
Open `admin/login.html`

Demo credentials:
- Username: `owner`
- Password: `maryscent`

## Included
- Responsive storefront
- Product search/filter/sort
- Cart with LocalStorage
- Checkout/order creation
- Order tracking
- WhatsApp ordering
- Admin dashboard
- Product management
- Shared online/offline inventory
- Offline POS
- Expense management
- Revenue/profit calculations
- Customer summary
- Activity log
- Business settings

## Important
This is a **frontend prototype**. LocalStorage is not secure enough for real authentication or production financial records. A real backend/database and payment gateway should be added before processing real customer payments or sensitive business information.

The supplied Mary’s Scent flyer is included in `assets/images/marys-scent-flyer.jpeg`, with product crops created from it for the demo.
